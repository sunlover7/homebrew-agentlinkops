# AgentLinkOps Homebrew tap

```sh
brew install sunlover7/agentlinkops/agentlinkops
```

The formula installs the `agentlinkops` package from npm (the same tarball `npm install -g agentlinkops` uses) and needs Node. Source, issues and releases: https://github.com/sunlover7/agentlinkops-cli. Documentation: https://docs.agentlinkops.com/.
